# صوتك — نسخة تجريبية محلية

هذه إعادة بناء مستقلة اعتمادًا على وصف التطبيق والشاشات التي شاركها المستخدم، وليست نسخة من جميع ملفات Kimi الأصلية.

## الوظائف
تسجيل دخول تجريبي، منشورات صوتية محلية، تشغيل التسجيلات، إعجابات محلية، ملفات شخصية، ومحادثات صوتية على نفس الجهاز فقط. لا يوجد خادم، ولا Firebase، ولا إرسال حقيقي بين مستخدمين. حساب demo@sawtak.app وكلمة المرور 123456 للتجربة؛ التحقق من كلمة المرور غير حقيقي. لا تستخدم بيانات شخصية فعلية.

## بناء APK باستخدام GitHub من الجوال
1. أنشئ مستودع GitHub جديد باسم sawtak.
2. ارفع محتويات ZIP إلى جذر المستودع (وليس مجلد sawtak الخارجي).
3. من تبويب Actions شغّل Build Sawtak APK عبر Run workflow.
4. إذا نجح البناء، نزّل sawtak-apk من Artifacts.

لم يتم تشغيل Flutter أو التحقق من نجاح البناء داخل هذه البيئة؛ استخدم سجل Actions لتشخيص أي مشكلة.
